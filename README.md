# まるつけ — 個別指導の採点記録

1コマ最大2名の個別指導で、講師がスマホを片手に持ったまま ○ / × / − を打ち込むための記録アプリ。

```
GitHub Pages          GAS ウェブアプリ        Google スプレッドシート
docs/index.html  ──▶  gas/*.gs         ──▶   シート7枚
```

画面は単一の HTML ファイル。ビルドもフレームワークもない。

## 2つのモード

`docs/index.html` の先頭にある `API_URL` の1か所で決まる。

| | API_URL が空 | API_URL に /exec の URL |
|---|---|---|
| 見た目 | デザイン資料つきのプロトタイプ | 全画面のアプリ |
| データ | 画面内のダミー（架空の生徒名） | Google スプレッドシート |
| 通信 | 一切しない | GAS 経由 |

URL を入れたあとでも `?demo=1` を付ければデモとして開ける。人に見せるときはこれを渡す。

デモは外部への参照を一切持たないので、ダウンロードしてダブルクリックしても同じように動く。
サーバーもネット接続も不要。

## 画面

| 画面 | できること |
|---|---|
| 記録 | 生徒・教材・ページ・見出し・大問・小問を指定して ○ × − を記録。取り消し可 |
| 復習 | 間違えた問題と未実施を別々に一覧。解き直しで記録画面に呼び戻す |
| 分析 | 単元別の正答率、日付ごとの記録。単元を押すとつまずきの内訳が開く |
| 教材 | 教材ごとの単元マスタと見出しの語彙 |

採点は通信を待たない。押した瞬間に画面へ入り、送信は裏で走る。
保存に失敗したときだけ、その1件を取り消して帯で知らせる。

## セットアップ

`gas/README.md` に手順がある。スプレッドシートを作り、`.gs` を貼り、
`initialize()` と `createTeacherManually()` を実行し、ウェブアプリとして公開する。

## 使い方

ログインはない。**鍵の付いた URL を開いた端末だけが使える。**

```
https://azumajinan.github.io/marutuke/?k=<鍵>
```

URL はスプレッドシートの **まるつけ → アクセスURLを表示** で確認する。
一度開けば端末が覚えるので、次からは鍵なしの URL でも入れる。

**この URL は生徒名と成績そのものと同じ重みを持つ。** 講師以外に渡さないこと。
漏れたら **まるつけ → アクセスURLを作り直す** で無効にできる。

## 残っていること

- 生徒の登録・編集、教材の新規登録フォーム（今はスプレッドシートに直接書く）
- つまずきの3色（黄・緑・赤）は、緑と赤が色覚特性によって見分けにくい。
  色だけに頼らないよう文字を併記してあるが、配色そのものは未決（`SPEC.md` 参照）
