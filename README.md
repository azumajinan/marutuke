# まるつけ — 個別指導の採点記録

1コマ最大2名の個別指導で、講師がスマホを片手に持ったまま ○ / × / − を打ち込むための記録アプリ。
現在はデザインプロトタイプの段階で、バックエンドは未着手。

## デモ

`docs/index.html` が動くプロトタイプ。GitHub Pages で公開している。

外部への参照を一切持たない単一ファイルなので、ダウンロードしてダブルクリックしても同じように動く。
サーバーもネット接続も不要。

**データはすべて画面内のダミー。通信も保存もしていない。生徒名も架空。**

## 触れるもの

| 画面 | できること |
|---|---|
| 記録 | 生徒・教材・ページ・見出し・大問・小問を指定して ○ × − を記録。取り消し可 |
| 復習 | 間違えた問題と未実施を別々に一覧。解き直しで記録画面に呼び戻す |
| 分析 | 単元別の正答率、日付ごとの記録。単元を押すとつまずきの内訳が開く |
| 教材 | 教材ごとの単元マスタと見出しの語彙 |

設計上の判断とその理由は、プロトタイプ本体の下部に「DESIGN DECISIONS」としてまとめてある。
